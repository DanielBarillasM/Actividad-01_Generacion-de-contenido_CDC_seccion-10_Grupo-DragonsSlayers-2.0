# Fuentes y licencias

## Fuentes técnicas

1. WebAssembly Community Group. [WebAssembly Core Specification 3.0](https://webassembly.github.io/spec/core/). Fuente primaria para instrucciones, validación, módulos, ejecución y formato textual.
2. Robert Nystrom. [Crafting Interpreters](https://craftinginterpreters.com/). Referencia para scanner, parser, AST, resolución de nombres y máquinas de pila.
3. Keith D. Cooper y Linda Torczon. *Engineering a Compiler*, tercera edición. Morgan Kaufmann, 2022.
4. Alfred V. Aho, Monica S. Lam, Ravi Sethi y Jeffrey D. Ullman. *Compilers: Principles, Techniques, and Tools*, segunda edición. Pearson, 2006.
5. Bytecode Alliance. [Wasmtime Documentation](https://docs.wasmtime.dev/). Runtime usado para validar y ejecutar el WAT generado.
6. Manim Community. [Documentación de Manim](https://docs.manim.community/). Herramienta de animación programática.
